## Projects

### 01 — Student Grade Management System
**Status:** Completed

A command-line Python program that manages student records and performs basic data processing.

**Features:**
- Stores student information using lists and dictionaries
- Displays names, ages, and marks
- Separates passing and failing students
- Sorts student records by marks
- Calculates total and average marks

**Concepts practiced:** Lists, dictionaries, loops, conditional statements, functions, sorting, and formatted output.

**Run:**
```bash
python3 01-student-grade-management.py
```

### 02 — TCP Port Scanner
**Status:** Work in Progress

An educational Python project exploring TCP socket programming, networking, and concurrent execution.

**Topics explored:**
- IPv4 and TCP sockets
- TCP connection attempts and timeouts
- Hostname resolution
- Exception handling
- Python threading

**Development note:** The current implementation requires improvements to thread management and error handling.

**Security note:** This project is intended for authorized testing and educational use only.
